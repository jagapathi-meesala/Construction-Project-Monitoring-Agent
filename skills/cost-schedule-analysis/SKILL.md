# Cost and Schedule Analysis
## Purpose
Analyze budget usage and schedule performance from user-supplied project measurements.
## Inputs
Approved budget, actual cost, planned progress, and actual progress.
## Processing
Calculate budget variance and schedule variance using explicit formulas.
## Outputs
Variance values, ratios, and status bands.
## Limitations
No procurement, invoice, or contract system is queried automatically.
## Expected behavior
Use deterministic arithmetic and reject invalid numeric inputs.
